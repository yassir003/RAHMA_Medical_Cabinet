## ✨ Overview

**Rahma Medical Cabinet** is a completely modern, sleek, and pixel-perfect dashboard application designed to simplify medical practice management. With built-in patient CRUD functionality, interactive modals for reporting, doctor appointments, and administrative staff management, this platform ensures a streamlined internal workflow wrapped in a beautiful, highly responsive interface.

## 🚀 Features

- **Dashboard Insights**: Get a birds-eye view of daily appointments, patient statistics, and clinic performance.
- **Patient Management**: Comprehensive CRUD (Create, Read, Update, Delete) capabilities for patient records.
- **Interactive Modals**: Seamless inline dialogs for quick reporting, rapid appointments, and registration.
- **Staff Administration**: Management tools designed for clinical staff and administration.
- **Beautiful & Responsive**: Completely fluid layout designed with high-end aesthetics prioritizing user experience.

## 🛠️ Getting Started

Follow these steps to get a local development environment running.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) installed on your machine.

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/yassir003/RAHMA_Medical_Cabinet.git
   cd RAHMA_Medical_Cabinet
   ```

2. **Install dependencies**:
   ```bash
   npm install
   # or yarn install / pnpm install / bun install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   # or yarn dev / pnpm dev / bun dev
   ```

4. **Launch**:
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
